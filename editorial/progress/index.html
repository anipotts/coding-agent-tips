how this is counted

Pages and headings come from the current canonical Markdown, including hidden chapters. “Written” means every leaf has content and no detected placeholder; it does not mean a chapter meets its reader’s needs or is launch ready.

Review and voice come from exact, fingerprinted evidence in the existing editorial ledger. Reading a page, changing its layout, or editing one sentence never approves its neighbors. “Unclassified” means a voice pass is not recorded; it does not claim the text sounds unlike you.

Media counts are placements, so responsive versions and video posters do not count as extra images. “Labeled examples” counts explicit example blocks; other code and example sections appear separately. Links count authored destinations, excluding the generated source footer. Local route visibility is separate from production.

File saves update this map automatically. New personal approvals still need a recorded observation; the map never invents them. A changed accepted passage is flagged for another review.
